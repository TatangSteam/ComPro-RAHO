# 🚀 ERD Quick Reference

## 📊 Database Entities (4 Tables)

```
┌─────────────────┬──────────────┬─────────────────────────────┐
│ Entity          │ Records      │ Purpose                     │
├─────────────────┼──────────────┼─────────────────────────────┤
│ Article         │ 50-200       │ Health articles & content   │
│ CompanyProfile  │ 1            │ Company information         │
│ Location        │ 5-20         │ Branch locations            │
│ Admin           │ 3-10         │ System administrators       │
└─────────────────┴──────────────┴─────────────────────────────┘
```

## 📋 Article Entity

**Categories**: `penyakit` | `tindakan-medis` | `kisah-pasien` | `partnership`

```sql
SELECT * FROM "Article" 
WHERE "published" = true AND "category" = 'penyakit'
ORDER BY "createdAt" DESC;
```

**Key Fields**:
- `slug` (unique) - URL identifier
- `category` - Article type
- `published` - Publication status
- `imageUrl` - Article image

## 📍 Location Entity

**Example Locations**: Jakarta, Bandung, Bali, Semarang

```sql
SELECT * FROM "Location" 
WHERE "city" ILIKE '%jakarta%'
ORDER BY "name";
```

## 👤 Admin Entity

**Roles**: `superadmin` | `admin` | `editor`

**Default Accounts**:
```
admin / admin123        (role: admin)
superadmin / super123   (role: superadmin)
editor / editor123      (role: editor)
```

```sql
SELECT * FROM "Admin" 
WHERE "isActive" = true 
ORDER BY "role";
```

## 🏢 CompanyProfile Entity

Usually contains **only 1 record** with company information.

```sql
SELECT * FROM "CompanyProfile" LIMIT 1;
```

## 🔑 Primary Keys

All entities use **UUID v4** as primary keys:
- Prevents enumeration attacks
- Better for distributed systems
- Auto-generated by database

## 🔒 Unique Constraints

- `Article.slug` - Unique URL identifier
- `Admin.username` - Unique login

## 📈 Recommended Indexes

```sql
-- Article indexes
CREATE INDEX ON "Article"("category");
CREATE INDEX ON "Article"("published");
CREATE INDEX ON "Article"("createdAt" DESC);

-- Location indexes
CREATE INDEX ON "Location"("city");

-- Admin indexes
CREATE INDEX ON "Admin"("role");
CREATE INDEX ON "Admin"("isActive");
```

## 🔐 Security Notes

- **Passwords**: bcrypt hashed (10 rounds)
- **IDs**: UUID v4 (not sequential)
- **Unique**: slug and username must be unique

## 📊 Common Queries

### Get Latest Articles
```sql
SELECT * FROM "Article" 
WHERE "published" = true 
ORDER BY "createdAt" DESC 
LIMIT 10;
```

### Count Articles by Category
```sql
SELECT "category", COUNT(*) 
FROM "Article" 
GROUP BY "category";
```

### Search Articles
```sql
SELECT * FROM "Article" 
WHERE "title" ILIKE '%keyword%' 
   OR "content" ILIKE '%keyword%'
ORDER BY "createdAt" DESC;
```

### Get Active Admins
```sql
SELECT "username", "role", "name" 
FROM "Admin" 
WHERE "isActive" = true;
```
